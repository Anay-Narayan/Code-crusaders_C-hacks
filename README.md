Terra Dash is a lightweight browser game built with HTML and JavaScript. Race through an exciting terrain-based challenge, collect points, dodge obstacles, and keep the momentum going as long as you can.

## Features

- Simple, responsive browser gameplay
- Built using HTML, CSS, and JavaScript
- Fast loading and easy to run locally
- Score tracking and replay-friendly mechanics
- Clean, game-focused design

## How to Play

1. Open the project in a browser.
2. Start the game from the index page.
3. Use the keyboard controls to move and avoid obstacles.
4. Try to survive as long as possible and beat your high score.

## Run Locally

Because this project is built with HTML and JavaScript, you can run it with any local web server or simply open the main HTML file in your browser.

### Option 1: Open directly
- Open `index.html` in your browser.

### Option 2: Run a local server
```bash
python -m http.server 8000
```
Then open:

```text
http://localhost:8000
```
