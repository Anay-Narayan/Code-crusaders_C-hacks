Terra Dash is a lightweight browser game built with HTML and JavaScript with the help from Claude ai by Anthrophic . Explore a simple, fast-paced terrain challenge, avoid obstacles, and keep your score climbing as long as you can survive.

## Features

- Built with HTML, CSS, and JavaScript
- Fast and lightweight browser gameplay
- Responsive, easy-to-run project
- Score-based gameplay loop
- Simple setup for local play

## How to Play

1. Open the project in a browser.
2. Launch the game from the main HTML file.
3. Use the controls to move and avoid hazards.
4. Try to survive as long as possible and beat your best score.

## Run Locally

Because this is a browser game, you can run it by opening the HTML file directly or serving the project locally.

### Option 1: Open directly
- Open `index.html` in your browser.

### Option 2: Run a local web server
```bash
python -m http.server 8000
```
Then visit:

```text
http://localhost:8000
```
